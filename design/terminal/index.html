HELP 指标说明
AA 智能指数
Artificial Analysis 用十多项独立评测（编程、科学推理、智能体任务、长上下文、知识可靠性等）综合算出的分数，越高越聪明。
思考档位
同一模型可设置不同的推理强度，如 max / xhigh / high / low。档位越高通常越聪明，但更慢更贵。
每任务成本
跑完整套智能指数评测时，平均每道题花费的 API 费用（美元）。它同时反映了单价和模型“想得多不多”。
高性价比区域
每任务成本低于中位数、智能指数高于中位数的区域。
全局最优前沿
帕累托前沿：在同等或更低成本下，没有别的模型比它更聪明。
输出速度
开始输出后每秒生成的 token 数（中位数）。
首字延迟
从发出请求到收到第一个 token 的时间。推理模型会先“思考”，所以通常更长。
总响应时间
一次典型请求从发出到完整返回的时间。
知识可靠性
AA-Omniscience 指数：答对加分、答错扣分、承认不知道不扣分，衡量模型会不会“一本正经地胡说”。
