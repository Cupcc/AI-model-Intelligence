# 微信小程序

原生小程序包含智能排名、模型筛选与本机记忆、成本散点图、多维指标排序表以及模型详情。数据来自 Artificial Analysis 的非官方中文整理。

## 本地开发

使用微信开发者工具导入 `miniprogram/`，项目配置使用小程序 AppID。工具生成的 `project.private.config.json` 是本机设置，不应提交。

## 数据更新

小程序现在采用「在线数据优先、内置快照兜底」：启动和回到前台时会请求 `config.js` 中的 HTTPS `dataUrl`，成功后写入本机缓存；网络不可用时继续使用最近一次缓存或随包快照。页面底部的同步状态可点击手动刷新，下拉页面也会强制刷新。

数据源仍由 GitHub Actions 每 6 小时更新 `docs/data.json`。生成随包快照：

```sh
python3 scripts/sync_miniprogram_data.py
```

仅更新随包快照时需要重新上传、审核和发布；线上数据更新不需要重新审核。远程服务必须符合微信 HTTPS 与 request 合法域名要求，API 密钥只能放在服务端，不能放入小程序代码包。

### 发布前配置远程更新

1. 确认 `https://cupcc.github.io/AI-model-Intelligence/data.json` 已能直接返回 JSON；如果使用自己的域名，只修改 `miniprogram/config.js` 的 `dataUrl`。
2. 在微信公众平台「开发 → 开发管理 → 开发设置 → 服务器域名」把 `dataUrl` 的域名加入 **request 合法域名**。必须是 HTTPS，不能填路径、端口或带查询参数。
3. 微信开发者工具中勾选「不校验合法域名」仅用于本地调试，正式版不能依赖此选项。
4. 发布后，Actions 生成的新 `docs/data.json` 会被已发布版本在下一次启动、回到前台或手动刷新时读取，不需要重新审核；只有修改小程序代码、域名或权限时才需要重新发布。

如果更换 GitHub 用户名、仓库名或数据托管地址，必须同步修改 `config.js` 并重新上传审核。远程响应必须保持与 `docs/data.json` 相同的数据结构（至少包含非空 `models` 数组，每项包含 `slug` 和 `name`）。
