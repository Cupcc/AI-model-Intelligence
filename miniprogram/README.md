# 微信小程序

原生小程序包含智能排名、模型筛选与本机记忆、成本散点图、多维指标排序表以及模型详情。数据来自 Artificial Analysis 的非官方中文整理。

## 本地开发

使用微信开发者工具导入 `miniprogram/`，项目配置使用小程序 AppID。工具生成的 `project.private.config.json` 是本机设置，不应提交。

## 数据更新

当前 `data/models.js` 是从 `docs/data.json` 生成的随包快照，页面显示数据更新时间；网站定时更新不会自动更新已发布的小程序。生成新快照：

```sh
python3 scripts/sync_miniprogram_data.py
```

更新快照后需要重新上传、审核和发布。要实现自动更新，需要部署符合微信要求的 HTTPS 数据服务、配置小程序 request 合法域名，并实现请求、缓存和失败回退。不得把 API 密钥放入小程序代码包。

## 上线

完善小程序主体、名称、头像、介绍及适用服务类目，办理小程序备案和其他适用资质；确认数据使用及展示权限。使用微信开发者工具上传，后台提交审核，审核通过后发布。
